# Local Only Policy (سياسة العمل المحلي الصارمة)

- المستودع الرسمي المعتمد للمشروع بطلب المالك: https://github.com/Moussa-Honda/AQSATI-GOOGLE-PLAY.git
- يمنع ربط المشروع بأي مستودع خارجي آخر غير المعتمد، ويمنع رفع أي مفاتيح سرية (مثل key.properties أو *.jks).
- هذا النظام هو "أقساطي" (Aqsati) ومستقل تماماً.
- النسخ الاحتياطي لـ Google Drive خدمة اختيارية مستقلة خاصة بأقساطي فقط.
- جميع عمليات البناء تتم محلياً فقط على الجهاز.
